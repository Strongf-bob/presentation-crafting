# Presentation Crafting

Скилл для создания презентаций под конкретную целевую аудиторию: от брифа до готовой деки, с выбором структуры по ЦА (YC Seed, YC Series A, «9 блоков», продажи, внутренние и т.д.).

## Что делает скилл

Перед созданием презентации скилл:

1. **Собирает базу** — задаёт вопросы про цель, ЦА, стиль, плотность текста, материалы. Не начинает работу, пока база не собрана и бриф не одобрен.
2. **Создаёт папку** — `presentations/<deck-name>/` (в текущем проекте), всю работу ведёт внутри неё.
3. **Пишет бриф** — `01-brief.md`: зачем презентация, ЦА, стиль, дизайн vs текст, сколько текста на слайд, какая структура выбрана и почему.
4. **Пишет спек слайдов** — `02-deck-spec.md`: сначала структура, потом каждый слайд с точным текстом, ссылками на картинки из `assets/`, акцентом и заметками докладчика.
5. **Собирает ассеты** — `assets/` с вложениями, которые попадают на слайды.
6. **Делает презентацию** — по умолчанию self-contained HTML (для генерации слайдов используется скилл `design-system`: токены, Chart.js, анимации).

## Структура репозитория

```
presentation-crafting/
├── SKILL.md                       # сам скилл: воркфлоу, preflight, чек-листы
├── references/
│   └── audience-structures.md     # ЦА → структура: YC, 9 блоков, дизайн-принципы
└── templates/
    ├── brief.md                   # шаблон брифа
    └── deck-spec.md               # шаблон спека слайдов
```

## Установка

Скопировать или симлинкнуть в каталог скиллов:

```bash
ln -s "$PWD/presentation-crafting" ~/.codex/skills/presentation-crafting
```

## Использование

Просто попросить сделать презентацию:

> Сделай питч-дек для инвесторов по нашему проекту

Скилл сам задаст вопросы для брифа, создаст папку и пройдёт весь воркфлоу.
