# Presentation Crafting

Скилл для создания презентаций под конкретную целевую аудиторию: от брифа до готовой деки, с выбором структуры по ЦА (YC Seed, YC Series A, «9 блоков», продажи, внутренние и т.д.).

## Что делает скилл

Перед созданием презентации скилл:

1. **Собирает базу** — задаёт обязательные вопросы (цель, ЦА, регламент, материалы, формат); стиль и плотность выводит сам по таблице ситуаций. Не начинает работу, пока база не собрана и бриф не одобрен.
2. **Создаёт папку** — `presentations/<deck-name>/`, всю работу ведёт внутри неё.
3. **Пишет бриф** — `01-brief.md`: зачем презентация, ЦА, регламент, стиль, какая структура выбрана и почему.
4. **Пишет спек слайдов** — `02-deck-spec.md`: сначала структура, потом каждый слайд с точным текстом, источниками цифр, ссылками на картинки из `assets/` и заметками докладчика.
5. **Собирает ассеты** — `assets/` с вложениями, которые попадают на слайды.
6. **Делает презентацию** — по умолчанию self-contained HTML по встроенному референсу (внешние скиллы не требуются); PPTX/PDF — по договорённости.
7. **Проверяет** — чек-лист верификации + обязательный фактчекинг в два захода: источники цифр и чтение «глазами члена борда».

Для малых внутренних дек (≤5 слайдов) — lite-режим: сжатый бриф в начале спека, без отдельного раунда одобрения.

## Структура репозитория

```
presentation-crafting/
├── SKILL.md                        # сам скилл: воркфлоу, preflight, lite-режим, чек-листы
├── references/
│   ├── audience-structures.md      # ЦА → структура: архетипы, плотность, регламент, YC, 9 блоков
│   └── html-deck.md                # сборка деки: HTML, токены, навигация, чарты, PPTX/PDF
├── templates/
│   ├── brief.md                    # шаблон брифа
│   └── deck-spec.md                # шаблон спека слайдов
└── examples/
    └── deck-spec-example.md        # пример заполненного спека (3 слайда)
```

## Установка

Скопировать или симлинкнуть в каталог скиллов:

```bash
ln -s "$PWD/presentation-crafting" ~/.codex/skills/presentation-crafting
```

## Использование

Просто попросить сделать презентацию:

> Сделай питч-дек для инвесторов по нашему проекту

Скилл сам задаст вопросы для брифа, создаст папку и пройдёт весь воркфлоу.
