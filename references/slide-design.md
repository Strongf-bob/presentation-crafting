# Визуальные правила слайдов (анти-слоп)

Правила «хорошего вкуса», чтобы слайды не выглядели сгенерированным мусором (AI slop). Применяются при сборке деки (вместе с `references/html-deck.md`) и проверяются на верификации. Плотность из брифа (минимум/средняя/плотная) — целевой уровень; лимиты типов слайдов ниже — механический максимум, который нельзя превышать ни при какой плотности. **Этот файл — единственный источник истины по числам типографики и лимитам типов; в остальных референсах — только отсылки к нему.**

## Типы слайдов и лимиты плотности

Каждый слайд в спеке имеет тип. Тип задаёт шаблон и максимум контента:

| Тип | Максимум на слайде |
|---|---|
| `title` | 1 заголовок + 1 подзаголовок (+ опционально изображение) |
| `section-divider` | 1 заголовок + 1 фраза |
| `content` | 1 заголовок + 4–6 буллетов (по 1–2 предложения) |
| `image-focus` | 1 заголовок + 1 изображение + 1 подпись |
| `comparison` | 1 заголовок + 2 колонки (по 3–4 пункта) |
| `quote` | 1 цитата + атрибуция |
| `code` | 1 заголовок + 1 блок кода (макс. 15 строк) |
| `feature-grid` | 1 заголовок + макс. 6 карточек |
| `timeline` | 1 заголовок + макс. 5 вех |
| `metrics` | 3–4 крупные цифры с подписями |
| `diagram` | 1 заголовок + 1 схема |
| `closing` | 1 вывод/CTA + контакт |

Превышение лимита = автоматическое разбиение на два слайда. **Никогда не уменьшать шрифт, чтобы вместить больше** — тело минимум 18pt, это не обсуждается.

## Типографика

| Элемент | Размер | Назначение |
|---|---|---|
| Заголовок | 36–48pt, bold | вывод слайда |
| Подзаголовок | 24–28pt | контекст |
| Тело | 18–24pt | контент |
| Подпись | 14–16pt | аннотации, источники |

- Максимум 2 семейства шрифтов на деку: характерный для заголовков + нейтральный для тела. У заголовочного должны быть Bold/Black начертания.
- Длина строки 45–75 символов, интерлиньяж 1,3–1,6.
- Тело — всегда по левому краю (никакого justify); по центру — только заголовки, цитаты, короткие фразы.

## Цвет

- **Правило 60-30-10:** 60% фон, 30% вторичный, 10% акцент. Акцентных цветов — 1–2 на деку.
- Максимум 3 цвета. Один цвет = одно значение во всей деке.
- Контраст по WCAG: тело ≥ 4,5:1, крупный текст ≥ 3:1.
- На тёмном фоне — не чисто белый текст (#e0e0e0), на светлом — не чисто чёрный (#333333).

## Сетка и воздух

- Поля консистентные (≈5% от краёв), элементы выровнены по невидимой сетке — ничего не «плавает» случайно.
- 40–50% пустого места на слайд. Пустое место = профессионализм; не заполнять каждый угол.
- Типовые раскладки: center stage (титул, цитата, ключевая цифра), split 50/50 (сравнение, картинка+текст), асимметрия 60/40 или 70/30, сетка карточек 2×2 или 3×2, full bleed с подложкой под текст.

## Анти-слоп (запрещённые паттерны)

- **Font soup** — больше 2 семейств шрифтов.
- **Color rainbow** — больше 3 цветов, нарушение 60-30-10.
- **Wall of text** — абзацы вместо тезисов; текст ниже 18pt «чтобы влезло». Плохо: «Наша платформа позволяет пользователям в реальном времени отслеживать остатки на складах, автоматически пересчитывать прогноз закупок на основе исторических данных и заранее формировать заявки поставщикам». Хорошо: «Остатки в реальном времени» · «Прогноз закупок по истории» · «Автозаявки поставщикам».
- **Clip art syndrome** — декоративные картинки и иконки без функции; каждый визуал обязан зарабатывать своё место.
- **Transition carnival** — зоопарк анимаций; максимум один тип появления, применённый последовательно.
- **AI slop aesthetics** — фиолетовые градиенты + Inter/Roboto везде + одинаковые карточки. У каждой деки должно быть своё визуальное лицо (из брифа: стиль, тон, бренд).

## Чарты и данные

| Данные | Правильный чарт | Избегать |
|---|---|---|
| Сравнение | Bar | Pie (>5 секторов) |
| Тренд во времени | Line | Bar (>10 периодов) |
| Часть целого | Stacked bar | Pie (>5 секторов) |
| Распределение | Histogram | Line |
| Связь | Scatter | Bar |

Упрощение чартов для слайдов: убрать/приглушить сетку, максимум 3–4 серии, подписи прямо на данных вместо легенды, ключевой инсайт выделен цветом или аннотацией («↑ 23% к базовой линии»), максимально крупные подписи осей (≥16pt). Сложные данные — progressive disclosure: обзор → деталь → вывод на отдельных слайдах.

## Доступность

- Информация не передаётся только цветом — дублировать подписями/паттернами/формой.
- `prefers-reduced-motion`: анимации отключаются, контент доступен статично.
- У изображений — alt-текст; навигация полностью с клавиатуры.

## Чек-лист полировки (перед показом)

- [ ] Шрифты и цвета консистентны по всей деке (акцент значит одно и то же везде)
- [ ] Весь текст ≥ 14pt (тело ≥ 18pt), контраст достаточен
- [ ] Воздуха 40–50%, нет «забитых» слайдов
- [ ] Нет висячих слов и кривых переносов в заголовках
- [ ] Лимиты типов слайдов соблюдены, превышения разбиты на отдельные слайды
- [ ] Ни один анти-слоп паттерн не сработал
- [ ] Проверено на целевом разрешении (1920×1080)
