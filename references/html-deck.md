# Сборка деки: self-contained HTML

Этот референс делает скилл самодостаточным: его достаточно для сборки `deck.html` без внешних зависимостей. Если установлен скилл `design-system` — его токены, чарты и валидацию можно использовать поверх этого файла, но он **не требуется**.

## Формат файла

- Один файл `deck.html`, self-contained: весь CSS и JS инлайн внутри файла, картинки — относительными путями в `assets/`.
- Слайд 16:9, базовый размер 1280×720, масштабирование под экран (transform scale или vw-единицы).
- Навигация: стрелки клавиатуры (←/→, Space), клик по краям слайда, прогресс-бар, счётчик «N / total».
- Шрифты — system font stack по умолчанию. Внешние шрифты (CDN) — только если это зафиксировано в брифе.

## Токены (CSS variables)

В начале `<style>` объявить `:root` с токенами; значения — из брифа (стиль, тон, брендбук, если есть):

```css
:root {
  --slide-bg: ...;
  --text-primary: ...;
  --text-secondary: ...;
  --accent: ...;
  --font-heading: ...;
  --font-body: ...;
}
```

Весь CSS слайдов использует только `var(--...)` — никаких захардкоженных цветов и шрифтов внутри правил. Тогда смена стиля = правка токенов в одном месте.

## Типографика и плотность

- Заголовок слайда: 36–48pt, заголовок = вывод («Выручка выросла в 5 раз», не «Наша выручка»).
- Тело: 24–32pt. Если не влезает — текста слишком много: сократить текст, а не уменьшать шрифт.
- Плотность — по шкале из `references/audience-structures.md` (минимум / средняя / плотная), уровень — из брифа с учётом формата подачи (живое / чтение).
- Важное — сверху: слайд читают сверху вниз.
- Декор по минимуму: без лишних иконок, анимаций и переходов.

## Чарты

- Данные чарта = данные из спека, цифры совпадают дословно.
- Если деку открывают онлайн — Chart.js через CDN (`https://cdn.jsdelivr.net/npm/chart.js@4`).
- Если нужна работа офлайн — простые SVG-чарты инлайн вместо Chart.js. Выбор фиксировать в брифе.

## Изображения

- Только относительные пути `assets/...` — никаких внешних URL без проверки.
- Скриншоты интерфейсов — по минимуму (они шумные); вместо них — простые схемы.
- Сгенерированные изображения и диаграммы — тоже в `assets/`, kebab-case; происхождение указать в спеке.

## Валидация перед показом

1. Открыть `deck.html` в браузере и пройти все слайды от первого до последнего.
2. На каждом слайде: ничего не вылезает за границы, текст читаем, чарт рендерится.
3. Навигация работает: стрелки, клик, прогресс-бар, счётчик.
4. Если доступен скриншот-инструмент — снять каждый слайд и проверить визуально.
5. Цифры на чартах совпадают с цифрами в тексте слайда и в спеке.

## PPTX и PDF

Оба формата — только если согласованы в брифе; по умолчанию делается только HTML.

- **PPTX** — генерация через `python-pptx` строго по спеку (тот же текст дословно, те же `assets/`). PPTX заказывают ради редактируемости, поэтому верность тексту важнее красоты.
- **PDF** — печать `deck.html` в PDF из браузера или headless Chrome; каждый слайд — страница 16:9.
